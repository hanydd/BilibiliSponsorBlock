跳过规则引擎：第一版实现与灰度验证

本版默认使用旧逻辑。行为页顶部只有一个灰度开关，同时控制配置页面和执行引擎：

| 开关 | 页面与播放行为 |
| --- | --- |
| 关闭（默认） | 经典行为页面，旧调度和快进逻辑 |
| 开启 | 新规则页面，新引擎负责跳过、快进、静音和逐片段卡片 |

切换前先释放旧引擎的调度、倍速、静音和卡片，再由新引擎按当前位置判断；暂停视频不会因此自动跳转。已打开的视频立即切换，不需要刷新。新旧页面共享已有配置。

侧栏只保留“行为”入口。开关状态会保存并同步到其他设置窗口；导航和旧页面链接不会开启灰度。shadow 保留为内部诊断能力，不再提供用户选择器；设置页读到旧的 shadow 配置时归为经典模式。当前没有接入远程百分比分组或自动放量。

代码按以下职责组织。

| 文件 | 维护内容 |
| --- | --- |
| `src/content/skipRules/types.ts` | 值类型输入、用户操作、单次经过、卡片与执行计划 |
| `src/content/skipRules/rules.ts` | 稳定规则编号与单片段资格判断 |
| `src/content/skipRules/engine.ts` | 先归一化片段策略，再组合进入/离开、用户意图、暂停、规划和卡片 |
| `src/content/skipRules/policy.ts` | 音乐、全片手动、最短时长、静音许可及来源限制的第一层规则 |
| `src/content/skipRules/planner.ts` | 已获准片段的相邻/重叠合并，不扩大到正常空隙 |
| `src/content/skipRules/runtime.ts` | 页面快照、真实视频事件、唯一计时器、速度/声音恢复、卡片发布、执行反馈 |
| `src/content/skipRules/bridge.ts` | 模式隔离及原有按钮/命令的兼容入口 |

纯引擎不访问 Config、DOM、计时器、网络或系统时钟。相同状态、片段、操作和播放器快照产生相同计划；输入状态不会被修改。runtime 负责读取原始片段和配置，策略转换在纯引擎第一阶段完成，规则单测无需创建视频元素。

实际规则编号与评审文档中的阶段编号对应关系如下。阶段描述仍见 `skip-rules-rollout.md`，以下是日志中使用的稳定编号。

| 编号 | 判断内容 |
| --- | --- |
| POLICY-INVALID | 无效区间、非普通跳过区间 |
| POLICY-DISABLED | 总开关、白名单或仅标记/忽略策略不允许执行 |
| POLICY-AUTO | 当前经过允许自动执行 |
| POLICY-MANUAL | 当前经过只能显示操作入口，或用户已取消自动处理 |
| USER-EXCLUDED | 用户关闭/隐藏后，本次经过排除 |
| USER-EXPLICIT | 明确跳过、撤销、恢复、关闭等操作 |
| ENTER-OUTSIDE-IN | 逐片段判断外→内，不区分前后方向 |
| ENTER-INSIDE-IN | 同一片段内拖动，保持当前经过，不重复处理 |
| PLAY-PAUSED | 暂停或缓冲期间不执行新的自动操作 |
| EDIT-TARGET | 编辑范围不包括该片段 |
| EDIT-PREVIEW | 草稿未被明确选为预览目标 |
| PLAN-MERGED | 获准的多个自动区间合并执行 |

日志以 `[SB Rules]` 开头，仅在决定变化时记录，复用现有本地日志导出。shadow 不操作视频、不创建卡片、不提交统计。它记录的是新引擎在真实输入上的判断，不能视为新引擎独立运行整条时间线的实测结果。

已经接入的操作包括：

- 按每个片段判断外→内、内→内、内→外；遵守现有段内进入设置。
- 暂停时拖动只更新状态；恢复时按最终有效落点处理。
- 跳过按钮立即跳转；撤销返回对应片段起点并防止本段立即重跳。
- 关闭卡片或弹窗隐藏片段，仅排除本次经过。段内拖动、暂停和数据刷新不解除；离开后再次进入重新判断。
- 预告取消与恢复保持同一卡片；预告关闭覆盖即将发生的一次经过。
- 合并直接跳过、连续快进、重叠快进使用逐片段卡片。
- 自动/手动静音与快进独立；离开范围恢复插件拥有的声音状态，尊重用户原本的静音选择。
- 暂停期间用户改倍速时不覆盖新选择。
- 编辑界面增加“编辑预览时包含其他片段”，默认关闭；草稿预览明确传递目标身份。
- 单独的精彩点仍走导航入口，完整视频标签不被当作跳过整个视频的命令。

对未另行指定的细节，第一版采用以下可核对的实现选择：

| 细节 | 第一版选择 |
| --- | --- |
| 卡片“暂停快进” | 作用于当前片段的本次经过，其他片段继续独立判断 |
| A、B 重叠时关闭 A | 从计划移除 A；B 仍有效时可继续处理，不自动形成全时间范围保护 |
| 关闭孤立编辑界面 | 当前正在查看的范围先保持手动，避免关窗立即跳走 |
| 全局不展示卡片 | 沿用现有隐藏提示语义，不把隐藏解释为片段排除 |
| 旧版持久隐藏记录 | 保留已有记录；新版新增的普通隐藏操作使用本次经过排除 |
| 规则执行异常 | 停止该页面的新版自动操作，恢复仍由插件拥有的速度/声音，记录错误；不立刻重跑旧版造成第二次跳过 |

撤销会对与目标直接重叠的自动片段建立本次防重跳保护，保证回到目标起点后不会立刻被另一个自动片段跳走。它与关闭卡片只排除自身的语义不同，不会扩大到远处不相关的片段。

验证入口：

- `npm run test-without-building -- --runInBand`：包含规则状态转换与 16 种相邻分类组合。
- `npx playwright test e2e/skip-rules.spec.ts`：新版操作、灰度设置、实际切换执行器、静音、预告、编辑与隐藏。
- `BSB_E2E_DIRECT=1 BSB_E2E_SKIP_ENGINE=rules npx playwright test e2e/notice-adjacent.real.spec.ts`：真实 B 站页面上测试 BV1eier6bEbQ 开头两段的 8 种组合。页面、视频和媒体事件真实，扩展片段数据使用固定快照。
- `npx playwright test e2e/notice-actions.spec.ts e2e/notice-lifecycle.spec.ts e2e/notice-speedup.spec.ts`：旧版提示与播放回归。
