跳过行为矩阵：用户意图、播放操作、卡片与多片段组合

日期：2026-09-25。核对基线：`b919d6df`。

本文是产品行为规格草案，不代表当前代码已全部实现。已按用户最新六项反馈修订；尚未确定的细节显式标为待确认。规则引擎与灰度方案另见 `skip-rules-rollout.md`。

已经确认的约束：每个片段对应自己的卡片；同一片段状态变化原地更新；相邻快进可以连续执行，但到边界应分别展示各片段；完成卡片倒计时退出；hover 保持操作位置稳定；新卡片从上方进入，关闭后向下补位；尽量保持原卡片样式；不妨碍播放器原生操作。

用户已明确：拖动按片段外/内关系判断，不按前后方向判断；同片段内拖动不追加处理；撤销回到对应片段；编辑可切换是否包含其他片段；点击跳过立即跳转；主动关闭/隐藏某张卡片会排除该片段。全局不展示卡片属于例外，只改变展示。用户进一步确认：第 2 项指视频暂停；主动关闭/隐藏只排除本次经过。

先统一术语。

| 维度 | 取值 | 含义 |
| --- | --- | --- |
| 分类策略 | 自动、手动、仅标记、忽略 | 决定这个片段是否主动处理、是否提示操作 |
| 片段动作 | 跳过、静音、精彩点、完整视频标记 | 不能因为都叫“片段”就都跳到终点 |
| 跳过方式 | 直接跳过、倍速经过 | 自动策略可以选择其中之一 |
| 用户意图 | 正常观看、向前定位、回看、撤销、重新处理、编辑、预览 | 同一个播放位置可能对应不同意图 |
| 播放状态 | 播放、暂停、缓冲、结束、切换视频 | 决定是否推进处理及视频时间倒计时 |
| 片段关系 | 分离、相邻、重叠、嵌套、同起点、同终点 | 决定能否合并执行、何时出现各张卡片 |
| 提示设置 | 显示/隐藏、预告开/关、完整/紧凑/淡化 | 只影响提示，不改变分类策略 |
| 临时限制 | 无、撤销保护、用户排除、取消快进、编辑限制 | 各有独立来源和作用范围，不按拖动方向推断回看 |

“手动”不等于“用户排除”。手动仍提供操作入口；主动关闭卡片后该片段不再成为自动或手动提示候选。排除 A 不应静默取消另一个 B；如果 B 独立覆盖相同时间，它是否也应被禁止跨越 A 的范围，是另一个待确认的产品选择。撤销导致的防重跳保护也不能用普通拖动规则代替。

“片段开始”指进入起点，“片段结束”指到达终点。相邻 A=[10,20]、B=[20,30]，20 秒时 A 完成、B 开始。未完成草稿只有起点，不能拿来执行跳过。

以下表格构成组合规则。最终行为依次看：本次用户意图、有效分类策略、片段动作、时间关系、卡片展示。并非每个维度的笛卡尔积都有意义，例如完整视频标记没有“倍速至终点”状态。

1．先确定单片段的基础行为。

| 有效策略 | 直接跳过模式 | 倍速模式 | 卡片 | 时间轴标记 |
| --- | --- | --- | --- | --- |
| 自动 | 到起点直接跳至目标终点 | 到起点开始倍速，到终点恢复 | 自动预告可选；执行/完成时显示 | 按标记设置显示 |
| 手动 | 正常播放，点“跳过”才跳至终点 | 正常播放，点“跳过”仍是立即跳过，不暗中改成快进 | 片段内显示待操作卡片 | 显示 |
| 仅标记 | 正常播放 | 正常播放 | 不自动弹卡片 | 显示 |
| 忽略 | 正常播放 | 正常播放 | 不自动弹卡片 | 不显示该类片段的普通标记 |

手动分类是否增加“开始快进”按钮，是独立的可选产品能力；本草案不把它混进已有“跳过”按钮。

| 片段动作 | 自动 | 手动 | 仅标记/忽略 |
| --- | --- | --- | --- |
| 跳过 | 按全局选择直接跳过或快进 | 点击后立即跳到终点 | 按上表 |
| 静音 | 仅在有效范围静音，离开后恢复应有声音状态 | 点击后静音当前片段剩余部分；可取消 | 不自动静音 |
| 精彩点 | 使用精彩点自己的导航规则，不视为普通删除区间；自动导航的适用条件需要单独确认 | 显示跳到精彩点入口，点击才定位 | 只标记或忽略 |
| 完整视频标记 | 作为视频级标签、分类策略条件，不直接跳完整个视频 | 不生成普通的片段内待跳过流程 | 遵守完整视频标签显示设置 |

静音片段上的“跳过这一段”若保留，应作为独立操作，不能让同一个按钮在静音和移动进度之间含糊切换。

2．再把进入片段的方式与分类策略相乘。

以下进入关系逐片段判断，与拖动方向无关。“段内进入”设置指现有“进入片段中间仍跳过”。落在片段内采用起点包含、终点不包含的规则。

| 操作/意图 | 自动 | 手动 | 仅标记 | 忽略 |
| --- | --- | --- | --- | --- |
| 自然播放进入 | 执行配置动作 | 待操作卡片 | 不处理 | 不处理 |
| 用户从片段外拖入片段内，段内进入设置开启 | 从落点处理剩余范围，向前/向后相同 | 仅显示待操作卡片 | 不处理 | 不处理 |
| 用户从片段外拖入片段内，段内进入设置关闭 | 不自动处理；提供手动入口 | 待操作卡片 | 不处理 | 不处理 |
| 用户在同一片段内拖动 | 不追加跳过、不重新启动已取消的快进；已有有效处理保持，更新位置/剩余时间 | 保留同一卡片，更新剩余范围 | 不处理 | 不处理 |
| 用户从片段内拖到片段外 | 结束不再有效的处理，恢复应有播放器状态 | 过期操作退出 | 不处理 | 不处理 |
| 用户从片段外拖到另一处片段外，跨过整段 | 不补做动作、不补弹完成卡片 | 不补弹 | 不处理 | 不处理 |
| 用户回拖到片段之前，随后自然走入 | 仍按自动策略，不自动推断回看豁免 | 待操作卡片 | 不处理 | 不处理 |
| 暂停时拖入/拖出片段 | 暂不自动移动进度或启动快进；更新候选卡片；恢复后以最终有效关系处理 | 更新待操作卡片 | 不处理 | 不处理 |
| 首次打开视频时落在片段内 | 播放开始后按自动策略处理；不主动播放 | 播放开始后提供手动入口 | 不处理 | 不处理 |
| 正常结束后明确重播/循环 | 作为新的经过重新判断 | 新经过可重新提供入口 | 不处理 | 不处理 |
| 插件直接跳到下一段起点 | 衔接下一段，不漏段 | 下一段待操作卡片 | 不处理 | 不处理 |
| 插件撤销返回片段内 | 回到该片段起点并保留撤销保护，不能按普通外→内再次自动跳走 | 返回正常观看 | 不处理 | 不处理 |
| 编辑器定位/预览 | 按“包含其他片段”开关决定其他段是否参与，目标预览需明确授权 | 同左 | 同左 | 同左 |

首次打开时显示预告/待操作卡片可以提前，但暂停或尚未开始播放时，插件不能替用户启动播放。用户第 2 项已明确指视频暂停：暂停期间不执行自动操作，拖动只更新卡片，恢复时按最终位置判断；不把它解释为卡片“暂停快进”按钮的范围选择。

重叠例子：A=[10,30]，B=[20,40]，从 15 拖到 25，对 A 是内→内，不追加操作；对 B 是外→内，按 B 的策略判断。不能只给整个 seek 贴一个“段内拖动”的标签。

暂停期间若外→内→外，恢复播放时不补执行途中经过的片段。若外→内→内，保留尚未处理的进入意图，以最终落点判断。已在段内暂停，之后内→内拖动，不因此新增一次自动处理。

3．卡片按钮与用户意图。

| 用户操作 | 播放结果 | 当前卡片变化 | 本次豁免 |
| --- | --- | --- | --- |
| 预告上取消自动处理 | 到起点后正常播放 | 原卡片变为可手动跳过 | 保护该片段；重叠自动动作不能越过它 |
| 预告上恢复自动处理 | 到起点执行原配置动作 | 原卡片恢复预告 | 移除对应豁免 |
| 待操作卡片点“跳过”/对应快捷键 | 立即跳过所指片段 | 原卡片变完成 | 明确执行只覆盖用户选择的目标 |
| 快进中点“跳过” | 立即跳至这张卡片对应片段终点 | 当前卡片变完成，后续段另行衔接 | 不默认跳掉另一个手动片段 |
| 快进中点“暂停快进” | 原位置停止快进的具体范围待确认 | 原卡片显示可恢复状态 | 当前段/整次连续任务的作用范围待确认 |
| 点“恢复快进” | 原位置恢复快进 | 原卡片恢复进行中 | 明确解除对应取消状态 |
| 完成卡片点“取消跳过” | 返回该卡片对应片段起点，不返回整个合并任务起点 | 原卡片变“可重新跳过” | 必须防止立即重跳；重叠段保护范围另行确认 |
| 点“重新跳过” | 跳至目标终点 | 原卡片变完成 | 解除对应豁免 |
| 静音卡片点“取消静音” | 恢复用户声音选择 | 原卡片提供重新静音入口 | 本次不再被相同/重叠自动静音强制静音 |
| 点关闭 X／主动隐藏这一张 | 排除该片段，并移除它对当前跳过、快进和静音的贡献 | 关闭且不自动重建 | 用户明确取消；仅本次经过，离开后再次进入重新判断 |
| 设置“全局不展示卡片” | 播放保持当前策略 | 隐藏提示，不生成用户排除 | 与主动关闭某张卡片严格区分 |
| 点卡片的倒计时暂停 | 播放不变 | 仅保持完成提示 | 不等于暂停视频或暂停快进 |

建议：手动点击跳过时只保证当前卡片目标，落到自动片段内后可继续自动处理。若要跳过多段手动片段，必须有明确的多段选择，不能借合并规则偷偷执行。

4．卡片状态与时钟。

下表描述主操作，不要求更换现有视觉样式。完成提示使用用户配置的停留时长，例如 2 秒；不把 2 秒写成所有用户的固定值。

| 片段/卡片状态 | 主操作 | 显示时间依据 | 何时结束 |
| --- | --- | --- | --- |
| 自动处理预告 | 取消自动处理 | 距起点的视频时间，随播放倍速换算 | 到起点原地变进行中或完成 |
| 已取消的预告 | 恢复自动处理/手动跳过入口 | 仍依据视频位置 | 进入片段后原地变待操作 |
| 手动待操作 | 跳过；静音段则为静音 | 当前片段剩余的视频时间 | 正常走过终点后失效；hover 不延长片段有效期 |
| 快进进行中 | 跳过、暂停快进 | 当前片段剩余视频时间，不借用合并任务终点 | 到本段终点原地变完成 |
| 用户暂停快进 | 恢复快进、跳过 | 视频仍会前进，操作只在目标范围有效 | 范围结束后恢复入口失效，不无限滞留 |
| 视频暂停/缓冲中的快进 | 保留进行中操作 | 视频时间停止，倒计时不走 | 播放恢复后继续 |
| 静音进行中 | 取消静音，可另有跳过入口 | 静音片段剩余视频时间 | 离开范围恢复声音，卡片进入完成态 |
| 已完成 | 取消跳过/回看 | 独立的提示停留时间 | 到时平滑退出；hover/焦点按既定规则暂停退出 |
| 撤销后待操作 | 重新跳过 | 对应观看范围的视频时间 | 范围结束或用户关闭 |
| 已被用户关闭/主动隐藏 | 无 | 无 | 对应片段已被排除，本次经过中刷新数据不能重新加入有效候选；离开后再次进入可以重新判断 |
| 编辑/投票详情展开 | 保留当前片段操作 | 展开本身不改变播放策略 | 不因其他卡片收起而挪走鼠标下的按钮 |

视频时间倒计时与完成提示停留时间要分开。暂停视频一定暂停前者；后者是否暂停沿用提示交互规则，不能重新变成“视频暂停了，预告却继续倒数”。

同一轮中同一片段的状态更新不播放入场动画，不新建第二张卡片。另一片段第一次出现才是新卡片。正常重播或离开后重新进入属于新的经过，可以再次出现；同片段内拖动不建立新的经过。提示去重与统计去重独立。

5．两个相邻跳过片段的全部分类组合。

此表 A=[10,20]、B=[20,30]，自然播放，无用户排除/撤销保护/编辑限制，提示允许显示。“自动”可以是直接跳过或快进，具体展开见下一表。这里的“忽略”和“仅标记”都不能被并入扩大跳过范围。

| A 策略 | B 策略 | 播放行为 | 卡片行为 |
| --- | --- | --- | --- |
| 自动 | 自动 | 可连续处理两段 | 各自一张；快进在交界交接，直接跳过显示两张结果 |
| 自动 | 手动 | A 处理到 20，B 正常播放等用户 | A 完成与 B 待操作可同时存在 |
| 自动 | 仅标记 | A 到 20 后正常播放 | 只有 A 卡片，B 留标记 |
| 自动 | 忽略 | A 到 20 后正常播放 | 只有 A 卡片 |
| 手动 | 自动 | 不点 A 就正常看 A，到 20 自动处理 B；点 A 后也衔接 B | A 按自身状态退出/完成，B 独立出现 |
| 手动 | 手动 | 各自需明确操作；跳 A 不等于同意跳 B | A、B 各自对应操作 |
| 手动 | 仅标记 | A 可手动跳过，B 正常播放 | A 卡片，B 仅标记 |
| 手动 | 忽略 | A 可手动跳过，B 正常播放 | 只有 A 卡片 |
| 仅标记 | 自动 | A 正常播放，到 B 自动处理 | 只有 B 卡片 |
| 仅标记 | 手动 | A 正常播放，进入 B 提示 | 只有 B 待操作卡片 |
| 仅标记 | 仅标记 | 都正常播放 | 无自动卡片 |
| 仅标记 | 忽略 | 都正常播放 | 无自动卡片 |
| 忽略 | 自动 | A 正常播放，到 B 自动处理 | 只有 B 卡片 |
| 忽略 | 手动 | A 正常播放，进入 B 提示 | 只有 B 待操作卡片 |
| 忽略 | 仅标记 | 都正常播放 | 无自动卡片 |
| 忽略 | 忽略 | 都正常播放 | 无自动卡片 |

在 A 上取消过的情况不能直接套用“自动→自动”。需要先应用豁免规则：A 被主动关闭时，将 A 从候选中移除再判断 B。暂停快进是否影响整次连续任务尚未确认；不能预先把 B 也当作被取消。

6．相邻自动片段的执行方式。

| A 的执行 | B 的执行 | 边界行为 | 提示 |
| --- | --- | --- | --- |
| 直接跳过 | 直接跳过 | 同一次执行中可合并到 30，避免停在 20 再跳一次 | A、B 分别显示完成卡片，不制造虚假的中间播放 |
| 快进 | 快进 | 保持快进速度；到 20 完成 A 并开始 B | A 倒计时退出，B 显示进行中，短暂共存 |
| 直接跳过 | 快进 | 跳至 20 后开始 B 的快进 | A 完成，B 进行中 |
| 快进 | 直接跳过 | 快进到 20，再立即跳至 30 | 两张各自完成，最终恢复用户倍速 |
| 静音 | 静音 | 边界不闪一下声音，到整体静音范围末尾才恢复 | 每个静音片段独立显示 |
| 跳过/快进 | 静音 | 到 B 时按 B 策略静音 | 不能因为 A 自动就让 B 的手动静音自动执行 |
| 静音 | 跳过/快进 | 按 B 执行，声音按落点是否仍需静音决定 | 跳出静音范围应恢复，不能遗留静音 |

当前全局快进开关通常让相邻自动跳过段采用同一种方式。混合行用于覆盖用户点“立即跳过”、短片段回退或设置改变，不要求新增逐段倍速配置。

7．重叠、嵌套与合并。

| 时间关系/策略 | 应处理的范围 | 应显示的卡片 |
| --- | --- | --- |
| A=[10,20]、B=[15,30]，都自动直接跳过 | 合并跳至 30 | A、B 各自完成 |
| 同样范围，都自动快进 | 10 开始 A；15 开始 B；20 完成 A；30 完成 B | 15～20 两张进行中；20 后 A 完成倒计时、B 仍进行中 |
| A=[10,30] 包住 B=[15,20]，都自动快进 | 只改变一次倍速，30 恢复 | 15 出现 B，20 完成 B，A 继续 |
| A、B 同起点 | 同时进入各自适用行为 | 稳定顺序，不随机交换位置 |
| A、B 同终点 | 在同一边界各自完成 | 各自退出，不能串行延后或重复创建 |
| A=[10,20]、B=[20.1,30] | 20～20.1 是正常内容，不因想要平滑就删掉 | 两张各自处理；连续快进也不应扩张实际标记范围 |
| A 自动、B 手动，B 延伸到 A 之后 | A 不因 B 延长终点；落在 B 内时提供手动入口 | A 完成，B 待操作 |
| A 自动且完全包住手动 B | 自动 A 可跨过其自身全部范围；B 不独立触发动作 | 不补造 B 的“自动跳过完成”卡片或独立完成统计 |
| A 手动、B 自动且部分重叠 | B 在自身起点可以处理；A 的手动策略不是保护观看指令 | A 若已因 B 的处理失效则退出，不冒充 A 被用户点击过 |
| 仅标记/忽略 B 与自动 A 重叠 | B 不扩大 A 的范围；A 的自身范围仍可正常处理 | B 不因被 A 跨过而突然出现完成卡片 |
| A、B 连锁重叠，C 手动且延伸更远 | 只合并自动 A、B；不借 C 再延长 | C 若在落点仍有效则显示待操作卡片 |
| 自动快进内嵌自动静音 | 两者同时生效，静音只覆盖它自己的有效范围 | 各片段状态独立，不把两种动作混成一个按钮 |
| 自动快进内嵌手动/仅标记/忽略静音 | 按静音片段自身策略处理 | 手动仅提供操作，其他不自动弹卡片 |
| 用户已明确要求观看某范围，与其他自动段重叠 | 建议保护该范围，不能被另一自动段直接跨走或加速；范围之外仍可处理 | 提供手动入口，不能显示成自动处理中 |

补充两点：同一个片段重复返回的数据不能变成多张卡片；不同片段即使起止相同也有各自身份，合并执行与是否要对完全重复内容做数据去重是两回事。

“未执行的手动 B 被自动 A 顺带跨过”与“自动 A、B 合并执行”必须区分。前者不生成 B 的完成结果；后者两段确实参与自动任务，各有完成卡片。

8．撤销位置已确认，影响范围需继续细化。

撤销返回所点卡片对应片段起点。若 A=[10,20]、B=[20,30] 合并处理，点 B 撤销回到 20 附近，不返回 A 的 10 秒，也不返回此前进入 B 的某个中途落点。边界精度只用于防止重复触发，不能改变用户可感知的目标位置。

| 情况 | 已确认行为 | 待确认细节 |
| --- | --- | --- |
| 单段完成后撤销 | 回到该段起点，卡片原地变可重新跳过 | 撤销保护何时结束 |
| 合并处理后撤销 B | 回到 B 起点，不能立即再被 B 跳走 | 重叠的 A/C 是否共同进入观看保护 |
| A 完成提示仍在、B 正快进，撤销 A | 回到 A 起点，按新位置更新 B 状态 | 与 A 重叠但独立的 B 如何保护 |
| 在暂停视频时撤销或跳过 | 必须保持暂停，不自动播放 | 显式用户操作不受自动暂停门槛限制 |
| 快进中点暂停快进 | 必须明确其与暂停视频的区别 | 只暂停当前段还是整次连续任务 |
| 主动关闭已完成的卡片 | 排除该次经过对应的片段，但不回退已经完成的跳转 | 本次经过已经完成时，关闭旧卡片不能屏蔽下一次新进入 |
| 主动关闭进行中的卡片 | 排除该片段，按仍有效的其他片段重新判断播放 | 重叠内容是否额外形成保护范围 |

主动关闭、撤销、暂停快进是三个不同动作；不要互相冒充，也不能由卡片退出动画或普通播放器事件隐式触发。

9．多卡片的展示和快捷键。

| 场景 | 行为约束 |
| --- | --- |
| A 完成、B 刚开始 | 两张短暂共存，A 不立即删除；B 从上方进入 |
| B 已有预告 | 原地更新 B，不再次入场 |
| 同时出现多张完成结果 | 稳定顺序，与片段时间顺序对应；不逐张重启整个堆叠动画 |
| 第一张退出 | 其余卡片平滑向下补位，按已确认的顺序处理收起与补位 |
| 快速上下扫过多个卡片 | 当前鼠标目标和按钮位置稳定；不要被上方收起带着移动 |
| 多张展开 | 详情仍向下展开，最下方预留展开空间；上方可按既定规则延迟收起 |
| 超过视频可用高度 | 上方折叠为原卡片堆叠，移入后访问同样的卡片；不增加独立列表样式 |
| 卡片自动完成时正在 hover | 原地改按钮/状态，保持位置；停留计时不重置成另一个默认值 |
| 主动关闭/隐藏 A | 排除 A 并重新计算剩余处理范围，不关闭 B。A 是唯一快进/静音来源时停止该动作；B 仍独立生效时可继续，不因 A 被关闭就强制恢复原速或声音 |
| 全局设置不展示卡片 | 不自动排除片段、不改变分类策略；手动操作是否保留播放器入口另行确认 |
| 默认 Enter 目标 | 建议优先当前有效的待操作/进行中卡片，完成卡片不抢走新片段的默认操作 |
| hover/键盘焦点在某张可操作卡片 | 按既定卡片目标规则执行，界面明确标出快捷键归属 |
| 没有有效插件操作 | 不吞 Enter 或其他按键；输入框内不触发播放器/跳过快捷键 |
| 点击卡片按钮之后 | B 站方向键、空格和其他原生操作仍正常；不需要逐个补快捷键代理 |
| 点击卡片周围空白 | 仍是播放器自身的点击行为 |
| 打开倍速/清晰度/音量菜单 | 播放器菜单优先显示并可操作 |
| 紧凑、淡化、完整提示模式 | 只改变视觉展示；完成/未完成、hover/焦点的含义一致 |

提示隐藏与手动操作入口的现有设置文案需要核对，不能在改造时悄悄改变其作用范围。

10．播放状态、配置变化与片段数据变化。

| 变化 | 期望行为 |
| --- | --- |
| 视频暂停/缓冲 | 不触发新的被动跳过；保留当前位置、意图和快进恢复条件；片段倒计时停止 |
| 用户暂停期间明确点“跳过” | 明确点击仍立即定位到目标并保持暂停；禁止的是暂停期间自动执行 |
| 继续播放 | 根据最终位置、未处理的进入意图、用户排除与最新片段数据统一判断；不补执行暂停期间已经失效的操作 |
| 快进中用户主动改倍速 | 尊重用户选择，建议退出本次自动快进并保护当前任务，不稍后恢复旧倍速 |
| 快进暂停时用户改倍速 | 更新后续恢复基准，不覆盖新选择 |
| 用户原本已静音 | 自动静音结束后仍保持用户静音 |
| 自动静音中用户明确打开声音 | 建议尊重用户，本次不再强制静音 |
| 多段静音相接/重叠 | 最后一个仍生效的静音范围结束后才恢复；尊重用户选择 |
| 刷新后范围缩短/成员删除 | 按新范围及时结束处理；不能继续加速已经正常的内容 |
| 刷新后范围延长 | 仅对仍允许自动处理的新增范围生效，不覆盖用户豁免 |
| 同 UUID 更新标题/分类/时间 | 更新已有卡片，不当新卡片入场；动作改变需重新按策略判断 |
| 暂停/编辑期间收到新片段 | 不因数据返回绕过暂停限制或编辑开关；回拖方向本身不构成限制 |
| 自动改为手动/仅标记/忽略 | 停止不再被授权的自动动作；卡片按新策略更新或退出 |
| 手动改为自动 | 建议不立即打断当前观看；后续正常进入再自动处理，当前保留显式操作 |
| 总开关关闭/加入白名单 | 停止插件自动处理并恢复应有播放器状态；不强制播放或跳转 |
| 隐藏某段/低票过滤/最短时长过滤 | 不参与新的自动任务；正在处理时重新核对有效范围 |
| 切视频、切 P、换视频元素 | 结束旧播放器任务；旧操作不能影响新视频。仅替换同一视频 DOM 不重置本次经过内的排除；离开片段后再进入或切换视频才重新判断 |
| 全屏、网页全屏、小窗、窗口缩放 | 调整卡片可用范围，保持片段身份与执行状态 |

快进倍速数值沿用现有设置语义。低于用户当前速度时不得反而降速；是否叠加、固定到目标值及上限应另列设置行为，不借此次状态整理悄悄改变。

11．特殊设置和数据来源不能绕过以上规则。

| 条件 | 建议约束 |
| --- | --- |
| 音乐视频自动处理等特殊开关 | 明确它覆盖哪些普通分类策略；用户明确排除、撤销保护及编辑开关限制始终优先 |
| 完整视频标记要求同类片段手动处理 | 生效后按手动矩阵执行，进入片段中间也不能重新升级为自动 |
| 弹幕生成片段 | 是否启用及是否自动由弹幕设置决定；确定策略后遵守相同外→内/内→内判断与撤销、排除规则 |
| 已保存但未明确预览的本地草稿 | 建议不因存在于草稿列表就被动自动跳过 |
| 明确预览草稿 | 授权目标预览；是否同时处理其他片段由编辑开关决定，其他段仍需遵守自己的分类策略与用户排除 |
| 导入/远端/YouTube 来源 | 保留既定来源资格；来源不能替代用户意图判断 |
| 只有起点、非法范围、超出视频时长 | 不执行无效跳转；有效范围的边界行为一致 |
| 精彩点与普通片段冲突 | 用户明确点精彩点时建议优先抵达并可观看，不立刻被另一自动规则拉走；自动精彩点规则另行确认 |
| 完整视频标签与卡片 | 标签不是普通完成卡片，不占用连续片段的堆叠状态 |

用户对六项选择的最新反馈如下，替代最初建议。

| 编号 | 结论 | 状态 |
| --- | --- | --- |
| D1 | 按每个片段判断外→内与内→内；外→内触发相应策略，内→内不追加操作；与方向无关 | 已确认；仍遵守分类策略和段内进入设置 |
| D2 | 视频暂停期间不做自动操作；拖动只更新卡片，恢复时按最终位置判断 | 已确认 |
| D3 | 撤销回到对应片段起点 | 已确认；重叠保护范围待确认 |
| D4 | 编辑可切换是否包含其他片段 | 已确认；建议默认不包含，默认值尚未确认 |
| D5 | 点击跳过按钮立即跳过 | 已确认 |
| D6 | 主动隐藏/关闭卡片仅排除本次经过；全局不展示卡片设置除外 | 已确认；独立重叠片段的作用范围见补充规则 |

编辑开关关闭时只授权当前目标的明确预览；打开时其他片段按自身有效策略参与，不能把手动、仅标记或排除的片段升级为自动。开关切换不应丢掉编辑目标或重建其卡片。

关于“完全排除”：本草案指从跳过/快进/静音候选与主动卡片中排除，不删除服务器数据，不投票，不修改整个分类。已隐藏的片段如何提供显式恢复入口需要在设置/片段管理中保留可达方式，不另造堆叠列表。

关闭一张卡片必须记录原因。只有用户主动关闭/隐藏才排除；完成后自动消失、切视频清理、堆叠暂时遮挡、全局不显示提示、布局卸载都不能生成用户排除。

排除生命周期已确认：只排除本次经过。以下是边界的建议解释，便于测试，不扩大为视频会话级排除：

| 关闭时机/后续操作 | 本次排除如何持续 |
| --- | --- |
| 在片段内关闭 | 持续到离开该段；在段内来回拖动、暂停、缓冲、刷新数据不解除 |
| 离开后重新进入 | 是新一次经过，重新按分类策略与段内进入设置判断 |
| 预告阶段关闭，尚未进入 | 排除即将发生的一次经过；不能因为当前仍在段外就立即失效 |
| 关闭预告后直接跨过整段 | 该次机会结束，不阻止以后重新进入 |
| 已经完成后关闭旧结果卡片 | 只关闭该次经过的结果，不禁止下一次进入 |
| 某次结果仍显示时，用户重新进入同片段 | 更新为新一次经过；旧结果的迟到事件不能取消新一次经过 |
| 自动倒计时退出/堆叠隐藏 | 不产生用户排除 |

独立重叠片段建议按各自身份判断：排除 A 不顺带排除 B；将 A 从合并范围中移除，B 若仍有效则按 B 的策略执行。若希望“关闭 A 就保护 A 的整段内容，即使 B 与它重叠也不跳”，那是额外的时间范围保护规则，当前不混入已确认的“排除该片段”。
